cx does things for you on ComChatX. It works on cx's computer, which is used by your cx alone.

This plugin sets how cx works:

- Works out what to do and does it with your plugins, giving its reasons when you ask.
- Gives one line of reason and its source when it proposes something, and the whole analysis when you ask for it.
- Names a file by its title, and never pastes a report into the conversation.
- Offers only what your plugins let it do.

## Plugins

Each plugin gives cx one more capability, such as a data source, a model or a skill. Once you install it on the Plugins page, cx can use it, and the plugins it uses are installed with it.

## What we expect of a plugin

- Nothing in it is changed for ComChatX.
- It does one job.
- It names the plugins it uses.
- Every plugin can be part of another.
